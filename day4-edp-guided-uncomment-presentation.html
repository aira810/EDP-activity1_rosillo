How to Enable a STEP
Uncomment the full block
/* STEP 3 START function onMouseMove(event) { ... } STEP 3 END */
  • Select block → Ctrl + /
  • Save file → refresh browser
  • If console error appears, revert and uncomment carefully again
STEP 0A + 0B
Activate camera movement first
0A · on load
Uncomment slight one-time camera movement so students see initial motion.
0B · animate loop
Uncomment orbit logic in animate() for continuous motion.
STEP 1 + STEP 2
Enable foundation methods in events.js
function paintBuilding(mesh, colorHex) { ... } function resetHud() { ... }
No listener yet — this just prepares helper behavior used by later steps.
STEP 3 + STEP 4 + STEP 5
Mouse move, click, and resize
  • STEP 3: uncomment onMouseMove in events.js and its mousemove listener in main.js
  • STEP 4: uncomment onClick and canvas click listener
  • STEP 5: uncomment onResize and window resize listener
STEP 6 + STEP 7
Hover updates and keyboard reset
  • STEP 6: uncomment updateHover + call it in the animation loop
  • STEP 7: uncomment onKeyDown + keydown listener (R resets selection)
When STEP 7 works, your mini-map interaction flow is complete.

Troubleshooting
If something breaks
  • Blank screen: check internet (Three.js CDN) and browser console errors
  • No interaction: confirm both handler and listener lines are uncommented
  • Syntax error: half-commented block in events.js or main.js
  • No code updates: save file and hard refresh browser
